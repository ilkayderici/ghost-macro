# Katkı / Contributing

*[English below](#english)*

GhostMacro'ya katkı vermek istediğiniz için teşekkürler.

## Nasıl katkı verilir

1. Büyük bir değişiklikten önce bir **Issue** açıp fikri konuşalım.
2. Repoyu fork edin, ayrı bir branch'te çalışın.
3. Derleyin ve iç testleri çalıştırın: `GhostMacro.exe --selftest sonuc.txt` → `ALL PASS` olmalı.
4. Arayüze eklenen her metin hem Türkçe hem İngilizce olsun: `L.T("Türkçe", "English")`.
5. Pull request açın; ne değiştiğini ve nasıl denediğinizi kısaca yazın.

## Haklar

Bu proje açık kaynak değildir; tüm hakları ilkay Derici'ye aittir.

Pull request göndererek şunları kabul etmiş olursunuz:

- Gönderdiğiniz katkı sizin özgün çalışmanızdır veya onu gönderme hakkınız vardır.
- Katkınızla ilgili tüm telif ve kullanım haklarını, süresiz ve geri alınamaz şekilde proje sahibine (ilkay Derici) devredersiniz. Proje sahibi katkıyı her türlü amaçla (ticari dahil) kullanabilir, değiştirebilir, lisanslayabilir.
- Katkınız için herhangi bir ücret veya karşılık talep etmezsiniz.

Bu şartları kabul etmiyorsanız lütfen pull request göndermeyin.

## English

Thanks for wanting to contribute to GhostMacro.

### How to contribute

1. Before a large change, open an **Issue** so we can discuss the idea.
2. Fork the repo and work on a separate branch.
3. Build and run the self-test: `GhostMacro.exe --selftest result.txt` → must report `ALL PASS`.
4. Every UI string must be in both Turkish and English: `L.T("Türkçe", "English")`.
5. Open a pull request with a short note on what changed and how you tested it.
